# Blockbench Shortcuts & Productivity Tips

## Essential Hotkeys
- `V`: Move tool
- `R`: Rotate tool
- `S`: Resize tool
- `P`: Pivot tool (crucial for setting bone rotation centers)
- `Space`: Play/Pause animation timeline
- `Ctrl + D`: Duplicate selected cube or group
- `Shift + Tab`: Toggle grid snap

## Common Pitfalls & Fixes
- **Z-Fighting (Flickering faces)**: Ensure overlapping cube faces are offset by `0.001` or delete interior hidden faces.
- **Wrong Rotation Center**: If an arm rotates around its middle instead of the shoulder, activate the Pivot Tool (`P`) and drag the pivot point to the shoulder joint.
