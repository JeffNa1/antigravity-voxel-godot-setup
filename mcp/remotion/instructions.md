# Remotion MCP Server

## Overview
The Remotion Model Context Protocol (MCP) server provides real-time access to Remotion documentation, APIs, and guidelines for programmatically creating videos with React.

## Available Tools
- `remotion-documentation`: Search Remotion documentation for components, hooks (`useCurrentFrame`, `useVideoConfig`, `interpolate`, `spring`), transitions, audio, Lambda, CLI commands, and rendering patterns.

## Recommended Workflows
1. Query Remotion documentation before generating complex animations or compositions.
2. Align all Remotion packages to the exact same version when installing dependencies.
3. For project-specific skills, use `npx remotion skills add` or the `/remotion-docs` skill.
